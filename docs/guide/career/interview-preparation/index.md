# Java面试题库

全面的Java面试题集合，涵盖Java基础、分布式、微服务、消息队列等核心知识点。

## 📚 题目分类

### Java 基础
涵盖Java核心知识点，包括语法基础、集合框架、并发编程、JVM等。

### 分布式
分布式系统设计、分布式事务、分布式锁、一致性算法等。

### 微服务
微服务架构设计、服务治理、服务注册与发现、配置中心等。

### Kafka消息队列
Kafka核心概念、分区机制、消费者组、性能优化等。

### RabbitMQ消息队列
RabbitMQ交换机、队列、消息确认机制、集群配置等。

## 🎯 使用说明

- 点击左侧菜单中的题目分类，查看对应分类下的所有题目
- 每个题目包含详细的解答和示例代码
- 建议按照分类系统化学习
