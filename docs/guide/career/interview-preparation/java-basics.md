# Java 基础

Java基础相关的面试题集合。

## 题目列表

### 1. Java核心概念

#### 1.1 面向对象
- 封装、继承、多态的理解和应用
- 抽象类和接口的区别
- 内部类和匿名类的使用场景

#### 1.2 集合框架
- ArrayList、LinkedList、Vector的区别
- HashMap、Hashtable、ConcurrentHashMap的实现原理
- TreeMap和LinkedHashMap的使用场景

#### 1.3 异常处理
- 异常体系结构
- checked异常和unchecked异常
- 异常处理的最佳实践

### 2. JVM虚拟机

#### 2.1 内存模型
- 堆、栈、方法区的区别
- 对象的内存布局
- 垃圾回收算法和垃圾收集器

#### 2.2 类加载机制
- 类加载的过程
- 双亲委派模型
- 自定义类加载器

### 3. 并发编程

#### 3.1 线程基础
- 线程的创建方式
- 线程的生命周期
- 线程同步机制

#### 3.2 并发工具类
- CountDownLatch、CyclicBarrier、Semaphore
- ReentrantLock和synchronized的区别
- 线程池的使用和原理

---

> 💡 **提示**: Java基础是面试的重点，需要深入理解每个知识点的原理和应用场景。
